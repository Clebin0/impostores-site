## 🚀 Como Começar

### 1. Setup Local
```bash
# Clone o repositório
git clone https://github.com/Clebin0/impostores.git
cd impostores

# Instale dependências
npm install

# Configure variáveis de ambiente
cp .env.example .env.local

# Inicie desenvolvimento
npm run dev
```

### 2. Verificar Estrutura
```bash
npm run check
```

### 3. Rodar Testes
```bash
npm run test
```

### 4. Build para Produção
```bash
npm run build
npm run start
```

### 5. Deploy na Vercel
```bash
vercel deploy --prod
```
