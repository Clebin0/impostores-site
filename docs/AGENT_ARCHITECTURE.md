# Multi-agent architecture

This repository is the earlier/alternate IMPOSTORES website. It should not receive an independent production agent integration until the canonical repository is selected.

## Proposed roles after consolidation

- Athletics concierge for approved FAQs.
- Events assistant for published event information.
- Freshman guide for onboarding content.
- Store assistant for catalog questions only.

## Boundaries

Do not duplicate credentials, deployments, content stores, or agent runtimes across both website repositories. Do not expose checkout or payment actions to an LLM. Keep this document as a planning note until the canonical repository is selected.
