# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

## [1.0.0] - 2024-03-27

### Adicionado
- Migração completa de HTML estático para Next.js 16
- Design system profissional com Tailwind CSS v4
- 8 páginas principais (Home, Eventos, Guia, Ação Social, Loja, Parceiros, Diretoria, Checkout)
- 25+ componentes React reutilizáveis
- Sistema de carrinho com localStorage
- Calendário interativo de eventos
- E-commerce com 8 produtos
- Checkout com PIX mockado
- Integração com Context API para estado global
- Phosphor Icons para ícones profissionais
- Responsividade completa (mobile-first)
- Animações suaves e transições
- Design tokens customizados para marca IMPOSTORES
- Documentação completa (INDEX, QUICKSTART, DEVELOPMENT, DEPLOYMENT)
- Testes unitários com Jest
- GitHub templates para PRs e Issues
- Vercel configuration otimizado
- Build check script para validação

### Características Técnicas
- Next.js 16 com App Router
- React 19 com TypeScript
- Tailwind CSS v4 com design tokens
- SWR para data fetching
- Fonte custom "Damages" para tipografia
- 8+ imagens de produtos geradas
- 6 logos de parceiros gerados
- 6 fotos de diretoria geradas
- OG Image para social media
- Manifest.json para PWA
- Robots.txt e Sitemap.xml para SEO

### Configuração
- ESLint para qualidade de código
- Jest para testes
- TypeScript strict mode
- PostCSS com Tailwind
- Vercel deployment pronto
