## 📞 Dúvidas?

Se não souber aonde colocar algo novo:

1. **Componente React?** → `src/components/`
2. **Função utilitária?** → `src/lib/utils.ts`
3. **Interface TypeScript?** → `src/lib/types.ts`
4. **Nova página?** → `src/app/[nome]/page.tsx`
5. **Documentação?** → Raiz do projeto (*.md)
6. **Script CLI?** → `scripts/`
7. **Imagem/Asset?** → `public/images/` ou `public/fonts/`
