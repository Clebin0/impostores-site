## 💻 Como Começar

### 1. Setup Local
```bash
git clone https://github.com/Clebin0/impostores.git
cd impostores
npm install
npm run dev
```

### 2. Deploy (Vercel)
```bash
npm run build
vercel deploy --prod
```

### 3. Customizar
- Edite cores em `globals.css`
- Adicione produtos em `data.ts`
- Crie novas páginas em `app/`
